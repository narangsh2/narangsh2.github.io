GooCalendar

개인정보처리방침

시행일·최종 수정일: 2026년 10월 29일

GooCalendar의 개발·운영자 narangsh2는 구글캘린더 일정을 날짜별로 조회하고 오프라인에서 마지막 저장본을 확인할 수 있도록 앱을 제공합니다. 이 방침은 앱이 어떤 데이터에 접근하고, 어떻게 사용·저장하며, 사용자가 삭제하거나 권한을 철회할 수 있는지 설명합니다.

1. 접근하는 데이터와 권한

사용자가 구글 계정을 선택하고 동의한 경우, Google Calendar API를 통해 다음 정보에 접근합니다.

  • 사용자가 접근할 수 있는 캘린더의 식별자·이름·색상 및 기본 캘린더 여부
  • 기본 캘린더 식별자에 포함될 수 있는 계정 이메일 주소
  • 조회 기간에 해당하는 일정의 식별자·제목·시작 및 종료 시간·종일 여부·장소·설명

요청하는 구글 권한은 다음과 같습니다.

https://www.googleapis.com/auth/calendar.readonly

이 권한은 캘린더와 일정을 읽기 위한 권한입니다. 앱은 구글캘린더에 일정을 생성·수정·삭제하지 않습니다. 구글 비밀번호는 앱이나 개발자에게 전달되지 않으며, 인증·권한 동의는 Google의 기능을 통해 진행합니다.

2. 이용 목적

  • 날짜와 시간에 따른 일정 목록 표시
  • 표시할 캘린더 선택, 일정 검색, 기간 선택과 과거 일정 조회
  • 일정의 시간·장소·설명 표시
  • 인터넷 연결이 없거나 조회에 실패한 경우 마지막 저장 일정 표시
  • 연결 계정과 마지막 저장 시각의 확인

3. 저장 위치와 보관 기간

마지막으로 정상 조회한 캘린더 목록과 일정, 계정 식별자, 조회 기간, 저장 시각은 휴대폰의 앱 전용 내부 저장소에 저장합니다. 표시할 캘린더에 대한 선택도 기기 안에 저장합니다. 새 조회를 모두 완료한 경우 저장본을 교체하며, 조회에 실패하면 이전 저장본을 유지합니다.

저장 데이터는 새 조회로 교체되거나 사용자가 앱의 삭제 기능·Android 앱 데이터 삭제·앱 제거를 실행할 때까지 보관됩니다. 앱의 자동 백업과 기기 간 데이터 전송에서 해당 데이터를 제외하도록 설정되어 있습니다.

앱이 직접 받는 접근 토큰은 API 요청을 위해 실행 중 메모리에서 사용하며 앱 파일에 기록하지 않습니다. Google Play 서비스는 자체 정책과 보안 기능에 따라 인증 정보·토큰을 관리할 수 있습니다.

4. 데이터 전송과 공유

앱은 구글 계정 권한 승인과 일정 조회를 위해 Google 서비스와 HTTPS로 통신합니다. 개발자는 캘린더 데이터를 수집하는 별도 운영 서버를 두지 않으며, 앱이 읽은 일정과 계정 식별자를 개발자의 서버로 전송하지 않습니다.

앱에는 광고나 사용 분석 도구가 없으며, 일정 데이터를 판매하거나 광고·마케팅 또는 AI 모델 학습을 위해 제공하지 않습니다. 각 사용자의 저장 일정은 각자의 기기에서 관리됩니다.

GooCalendar에서 Google API를 통해 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책과 그 제한된 사용(Limited Use) 요건을 준수합니다.

5. 저장 데이터 삭제 및 권한 철회

  1. 기기 내 데이터 삭제: 앱의 연결 관리에서 ‘연결 정보와 저장 일정 지우기’를 선택합니다. Android 설정에서 앱 데이터를 삭제하거나 앱을 제거할 수도 있습니다.
  2. 구글 접근 권한 철회: Google 계정의 서드 파티 앱 및 서비스 관리에서 GooCalendar 또는 최초 등록한 앱 이름을 찾아 연결을 삭제합니다.

기기 저장 데이터 삭제와 구글 권한 철회는 별개입니다. 권한을 철회하더라도 이미 기기에 저장된 목록을 지우려면 위 데이터 삭제 기능을 함께 실행해주세요. 이 과정은 구글캘린더 원본 일정을 삭제하지 않습니다.

홈페이지는 앱에서 조회한 구글캘린더 일정을 표시하거나 수신하지 않습니다.
